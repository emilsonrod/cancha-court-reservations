# Cancha Court Reservations

Actúa como un desarrollador frontend especializado en aplicaciones web modernas.

Quiero crear una aplicación web para gestionar reservas de espacios deportivos.

La aplicación debe tener:

1. Una página principal con un encabezado atractivo.

2. Una sección de bienvenida que explique el servicio.

3. Un catálogo de canchas deportivas disponibles.

4. Tarjetas que muestren fotografías, nombre, ubicación y precio de cada cancha.

5. Un botón para reservar cada espacio.

6. Un formulario para registrar una reserva con nombre del cliente, fecha y hora.

7. Una pantalla de confirmación de reserva.

Utiliza un diseño moderno, profesional y adaptable a dispositivos móviles.

Organiza los componentes de forma clara, utiliza colores relacionados con el deporte y proporciona una experiencia de usuario sencilla e intuitiva.

Quiero una primera versión visual e interactiva de la aplicación.
